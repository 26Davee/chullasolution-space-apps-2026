# data/missions/

| File | Content |
|---|---|
| `missions.json` | 16 missions in English and Spanish: goal, steps, triggers, reward stars and the science card (fact + source). |
| `upgrades.json` | Upgrade tree: cost in stars, effect and a science card for each upgrade. |
| `supplies.json` | Starter inventory and the modules delivered after each mission. |

Numbers in these files are game units unless a NASA source is cited. See `docs/DATA_PROVENANCE.md`.
