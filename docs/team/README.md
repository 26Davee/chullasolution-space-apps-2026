# Hackathon working documents

Documents the team wrote during the 48 hours of the hackathon to coordinate six people working on one Godot project. They are kept for transparency; some describe earlier versions of the design.

| File | Content |
|---|---|
| `DISENO_JUEGO.md` | First game design document (Saturday morning). Ages and some mechanics changed later. |
| `QUIEN_TOCA_QUE.md`, `CONTRIBUTING.md`, `GUIA_GIT.md`, `CONTRATOS.md` | Folder ownership by seat, Git workflow and data contracts between seats. |
| `UI_*.md`, `AUDITORIA_INTERFAZ_TUTORIAL.md` | Interface integration notes and tutorial audit. |
| `PROGRESSION_API.md`, `MISSIONS_DATA.md` | API guide for missions, saving and upgrades, and the mission data format. |
| `registro/` | Per-person logs of AI use, third-party material and NASA data. |
| `pull_request_template.md` | Checklist used for pull requests. |
