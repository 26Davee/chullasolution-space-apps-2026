# Registros personales

Cada puesto tiene **su propio archivo** aquí: `puesto-1.md` a `puesto-6.md`. Solo su dueño lo edita, y por eso nunca chocan.

En cada uno se anota, al momento y no al final:

1. Lo que se hizo con **IA**.
2. Lo que se usó de **terceros** (imágenes, sonidos, fuentes, modelos), con autor y licencia.
3. Los **datos de NASA** usados, con enlace oficial, fecha y unidades.

El puesto 1 junta los seis archivos en [`../../AI_USE.md`](../AI_USE.md), [`../../ASSETS_LICENSES.md`](../ASSETS_LICENSES.md) y [`../../DATA_PROVENANCE.md`](../DATA_PROVENANCE.md) antes del envío.
