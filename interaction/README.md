# interaction/

Player input in the 3D world.

| File | Purpose |
|---|---|
| `click_to_move.gd` | Click or tap to move the astronaut robot. |
| `placement_system.gd`, `ghost_preview.gd`, `hologram.gdshader` | Placing modules inside the dome with a hologram preview. |
| `route_planner.gd` | Routes for ice trips around craters. |
| `station_bindings.gd` | Clickable machines (processor, oxygen generator, charger). |
| `supply_drop.gd` | Supply deliveries after missions. |
| `animador_astronauta.gd`, `visor_astronauta.gd` | Astronaut animation and visor. |
